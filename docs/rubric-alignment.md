# Rubric Alignment

## Problem Identification

CareHub AI addresses delayed bedside risk detection and nursing workload in multi-patient care settings.

## Conceptual Innovation

The project combines pressure and IV signals into prioritized, explainable nurse actions instead of isolated sensor alarms.

## Integration Strategy

The system is modular and can attach to existing beds, cushions, and IV stands.

## System Design

The design has clear layers: sensors, edge device, AI risk engine, dashboard, and nurse action.

## Improvement Plan

Future versions can add certified vital-sign device integration, full mattress mapping, mobile notifications, and ward-level analytics.
