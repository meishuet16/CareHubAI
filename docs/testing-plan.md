# Testing Plan

## Pressure Tests

- Short pressure should not create an urgent alert.
- Prolonged high pressure should create a repositioning alert.
- Moving pressure to another zone should reduce previous zone risk.

## IV Tests

- Low remaining IV fluid should create a monitoring alert.
- Abnormal flow should create an urgent alert.

## Dashboard Tests

- Urgent beds should appear before monitor beds.
- Acknowledged alerts should leave the active priority queue.
- Stable beds should remain visible in the ward overview.
