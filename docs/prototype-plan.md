# Prototype Plan

The physical prototype should be a scaled smart bedside model.

Core parts:

- Mini bed or cushion model.
- 4-zone pressure mat.
- Simulated IV bag.
- ESP32 edge device.
- LED and buzzer alerts.
- Laptop nurse dashboard.

The dashboard can show one real prototype bed and three simulated beds, allowing the team to demonstrate multi-bed alert prioritization without building four physical beds.
