# CareHub AI Safety Boundaries

CareHub AI is a nurse support prototype, not a diagnosis or treatment system.

## What It Does

- Highlights pressure and IV patterns that need human attention.
- Prioritizes which bed should be checked first.
- Explains the sensor reason behind each alert.
- Records whether a nurse has acknowledged the alert.

## What It Does Not Do

- It does not diagnose patients.
- It does not automatically control medication or IV flow.
- It does not move the patient automatically.
- It does not replace nurse judgement.

This boundary keeps the prototype realistic for a student hardware build and aligned with safer healthcare technology expectations.
